# sabun 品質ゲート

このファイルはCIで動かすテストの狙いを明示する。単なる「正常に実行できるか」ではなく、**見逃してはいけない変更でテストを省略しないこと**を契約とする。

| シナリオ | 期待 |
| --- | --- |
| 既存メソッド本体だけの変更 | 観測済みの依存テストだけ選択 |
| callback / route / 新規Rubyファイル | 安全側に全件 |
| JS/CSS・設定・テスト自体の変更 | 安全側に全件 |
| baselineの欠損・不整合 | 空集合ではなく全件 |
| E2Eの認証失敗・同時実行・ID不一致 | 計測を拒否 |
| RSpec実行時の依存収集 | 実RSpecプロセスでファイル依存が記録される |
| Playwrightの通常実行 | 計測用環境変数がなくても動く |

## 次の品質ゲート
